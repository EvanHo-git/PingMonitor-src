# macOS 首次打开说明

`PingMonitor.app` 由 **ad-hoc 自签名** 打包（本机无 Apple 开发者证书）。macOS 的 Gatekeeper 不信任此类签名，第一次双击通常会被拦截。按以下步骤一次即可永久放行，**全程约 30 秒**。

---

## 方法一：右键打开（最简单）

1. 在 `Finder` 中找到 `PingMonitor.app`；
2. **按住 Control 键单击**（或右键单击）该图标；
3. 在菜单中选择 **"打开"**；
4. 弹出确认框，再次点击 **"打开"**。

之后该 app 已被系统记住，以后双击即可正常启动。

---

## 方法二：系统设置放行（适用于方法一仍被拦）

1. 先双击一次 `PingMonitor.app`，看到"无法打开"提示后**不要慌**；
2. 打开 **系统设置 → 隐私与安全性**；
3. 在下方"安全性"区域会出现一行：
   > "PingMonitor.app" 已被阻止，因为其开发者无法验证。
4. 点击右侧的 **"仍要打开"**；
5. 再次确认 **"仍要打开"**，即可启动。

---

## 常见问题

**Q：为什么不能直接双击打开？**
A：苹果要求分发的 app 需经 Apple 公证（688 元/年的开发者账号）。本工具采用零成本 ad-hoc 签名，仅用于内部使用，故需手动放行一次。这是 macOS 的安全机制，不是程序损坏。

**Q：提示"应用已损坏，无法打开"？**
A：同上，走方法二在"隐私与安全性"中点"仍要打开"即可。若仍不行，在终端执行一次放行命令（需输入开机密码）：
```bash
xattr -cr /Applications/PingMonitor.app
```
（将路径替换为 app 实际所在位置）

**Q：换一台 Mac 还需要再操作一次吗？**
A：是的。ad-hoc 签名绑定本机，拷贝到其他 Mac 需各自放行一次。如需彻底免拦截，请使用正式 Apple 开发者证书重新签名（见 README 第九节）。

**Q：数据存在哪？**
A：`~/Library/Application Support/com.evan.pingmonitor/`，含目标清单、参数配置与 `exports/` 导出目录。卸载时删除该目录与 app 即可。
