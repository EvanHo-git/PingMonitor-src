# Windows 使用说明

`PingMonitor.exe` 为单文件可执行程序，双击即运行，终端机器**无需安装 Python 或任何运行时**。

---

## 一、首次运行

1. 将 `PingMonitor.exe` 拷贝到任意目录（建议放在专用文件夹，如 `D:\Tools\`）；
2. 双击 `PingMonitor.exe`；
3. 若被 **Windows SmartScreen** 拦截（提示"Windows 已保护你的电脑"）：
   - 点击 **"更多信息"**；
   - 点击 **"仍要运行"**。
   > 原因：exe 无代码签名证书（非病毒）。如贵司有代码签名证书，可用 `signtool` 自行签名消除该提示。

---

## 二、使用要点

- **添加目标**：在"目标管理"中手动添加，或点"导入"从 `.txt` / `.csv` 批量载入（每行一个 IP 或域名，CSV 支持 `名称,地址` 两列）。
- **开始监测**：设置好参数后点"开始监测"，趋势图与目标表实时刷新。
- **导出数据**：点"导出"，选择 **CSV**（供 Excel 透视）或 **JSON**（供脚本/AI 二次分析），按时间范围筛选。
- **持久化**：目标清单、探测参数、界面主题会自动保存，下次打开自动恢复。

---

## 三、Windows 平台的特殊限制

| 限制 | 说明 |
|------|------|
| **包间隔固定 1 秒/包** | Windows 系统 `ping` 不支持自定义发包间隔（无 `-i` 参数）。界面已对 Windows 用户明确标注，参数中的"发包间隔"在 Windows 下不生效。 |
| 全量刷新偏慢 | 受 1 秒/包限制，20 目标全量刷新约 6 秒（macOS 约 3 秒）。属系统层限制，非工具缺陷。 |
| 免管理员 | 采用系统 `ping` 命令（非原始套接字），双击即可运行，无需右键"以管理员身份运行"。 |

---

## 四、数据目录

配置与导出位于：
```
%APPDATA%\com.evan.pingmonitor\
├── config.json        # 目标清单 + 参数 + 主题
└── exports\           # 导出的 CSV / JSON
```
> 该目录在用户账户下，重装系统或换机不会随 exe 带走，请按需备份 `exports/`。

---

## 五、故障排查

| 现象 | 处置 |
|------|------|
| SmartScreen 拦截 | "更多信息 → 仍要运行" |
| 某目标 100% 丢包 | 用 `ping 地址` 在 CMD 验证是否目标侧禁 ICMP |
| 杀毒软件误报 | 将 exe 加入信任/白名单（零依赖单文件偶被静态启发式误判） |
